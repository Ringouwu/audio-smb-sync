# MacBook SMB 配置

1. 打开“系统设置 → 通用 → 共享”，开启“文件共享”。
2. 点击共享文件夹列表的“+”，添加用于接收录音的专用目录，例如 `AudioUploads`。
3. 在“用户”中添加专用 macOS 用户，权限设为“读与写”；不要使用管理员账户。
4. 记录 MacBook 在当前局域网的 IPv4 地址，例如 `192.168.1.20`。建议在路由器中为此 MacBook 保留该地址。
5. 在 App 中填写：主机 `192.168.1.20`、共享名 `AudioUploads`、该用户的用户名和密码。

目标地址形如：`smb://192.168.1.20/AudioUploads/`。

## 检查方法

- 手机与 MacBook 必须在同一局域网。
- MacBook 不能休眠或关机；试点期间建议接电源并关闭自动睡眠。
- 点击 App 的“测试连接”。它会创建并删除一个短暂测试文件，不会写入录音。
- 若连接失败，依次核对局域网、IP、共享名、用户名、密码，以及该用户的读写权限。
