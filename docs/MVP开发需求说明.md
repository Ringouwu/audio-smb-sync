# 录音 SMB 同步 Android MVP：开发需求说明

## 1. 目标

App 只负责将销售手机中、经用户授权读取的通话录音同步到局域网 SMB 共享目录，供后端质检脚本读取。

```text
手机录音文件 → 解析录音发生时间 → 统一命名 → SMB 上传 → 后端质检脚本
```

不做 App 自行通话录音、转码、质检评分、账号体系或 NAS 管理。手机原始录音永不删除。

## 2. MVP 功能

### 2.1 首次设置

设置页包含以下字段：

| 字段 | 规则 |
|---|---|
| 销售手机号 | 统一命名开启时必填。仅接受 11 位数字；输入 `+86` 时自动去除前缀。不可依赖系统自动读取。 |
| 设备名称 | 必填；用于可选的 SMB 子文件夹名称，例如“张三”。 |
| 录音文件夹 | 通过 Android 系统目录选择器授权。 |
| SMB 服务器地址 | 必填，只填写 IP 或主机名，例如 `192.168.110.28`；不填写 `smb://`。 |
| 共享文件夹名 | 必填，例如 `SharedFolder`、`岗位`。 |
| 登录方式 | 单选：`访客模式（无账号密码）` / `账号密码登录`。 |
| SMB 用户名、密码 | 仅在“账号密码登录”时显示且必填；密码使用 Android Keystore 加密保存。 |
| 按设备名称建文件夹 | 勾选项，默认关闭。 |
| 统一命名上传 | 勾选项，默认开启。开启时使用“手机号_时间戳”；关闭时保留原文件名。 |
| 自定义时间正则 | 可选。第 1 个捕获组必须是 14 位 `yyyyMMddHHmmss` 时间。 |
| 自动同步 | 勾选项。可关闭，或选择每日定时、每隔 N 分钟。 |
| 延后同步 | 输入 N 分钟后执行一次，独立于自动同步开关。 |
| 上传复核 | 单选：文件大小校验（默认）/ SHA-256 严格校验。 |

### 2.2 SMB 登录和目录规则

1. 支持 SMB2/SMB3，禁止 SMB1。
2. 访客模式不得要求用户名或密码；以 Guest/匿名会话访问共享目录。
3. 账号密码模式使用填写的用户名和密码访问。
4. 共享名及子目录必须按 URL 路径正确编码，中文共享名“岗位”必须可用。
5. 不勾选“按设备名称建文件夹”时，目标目录为：

   ```text
   smb://服务器/共享名/
   ```

6. 勾选后，若子目录不存在则创建，目标目录为：

   ```text
   smb://服务器/共享名/设备名称/
   ```

   例如设备名称为“张三”：

   ```text
   smb://192.168.110.28/岗位/张三/
   ```

7. “测试连接”必须依次验证：可连接、可进入目标目录、必要时可创建子目录、可创建并删除临时测试文件。
8. 临时测试文件和上传临时文件均使用 `.uploading` 后缀；后端脚本只读取正式音频文件。

### 2.3 扫描、上传与重试

1. 每天约凌晨 02:00 通过 WorkManager 扫描一次；“立即同步”可手动触发。
2. 不转码，保留原始音频扩展名；首期处理 `mp3`、`m4a`、`amr`、`aac`、`wav`、`ogg`。
3. 使用 `来源 URI + 文件大小 + 修改时间 + 指纹` 去重。
4. 上传前写入 `文件名.uploading`，流式复制后校验远端大小，校验成功才重命名为正式文件。
5. 状态仅保留：待上传、上传中、已上传、失败。
6. 网络中断、服务器离线、认证失败、无权限等失败应记录具体原因；WorkManager 使用指数退避重试。

## 3. 统一文件命名

### 3.1 正式命名

服务器中的正式文件名固定为：

```text
销售手机号_录音开始时间.原始扩展名
```

示例：

```text
13800138000_20260717153025.m4a
```

- 手机号：11 位纯数字。
- 录音开始时间：仅数字，固定 `yyyyMMddHHmmss`，使用手机本地时区。
- 不使用同步时间。

### 3.2 时间解析原则

不同品牌、系统版本与拨号器的原始命名不一致，因此不采用 LLM 识别，也不依赖单一正则。采用“解析规则档案（Profile）”。每台试点手机选择一个档案，扫描最近文件时先预览解析结果，由管理员确认。

```text
原文件：张三@189xxxx_20241016150200.mp3
规则：华为/荣耀-连续14位时间
识别时间：20241016150200
生成文件：13800138000_20241016150200.mp3
```

每个规则档案包含：

| 字段 | 说明 |
|---|---|
| 名称 | 例如“华为/荣耀-14位时间”“自定义规则”。 |
| 正则表达式 | 从原始文件名捕获时间整体或年月日时分秒字段。 |
| 时间格式 | 例如 `yyyyMMddHHmmss`，或中文年月日字段组合。 |
| 时区 | 默认手机本地时区。 |
| 样例文件名 | 设置页用于预览和确认。 |

首期内置：华为/荣耀、MIUI/HyperOS、ColorOS/realme/vivo、三星及自定义规则。实际是否可读取文件仍取决于该系统是否允许用户通过目录选择器授权该录音目录；Google 电话等私有目录无法授权读取的机型不进入首期试点。

### 3.3 异常处理

1. 仅当“统一命名上传”开启时，时间无法解析或日期无效：不上传，状态为失败，原因写明“未匹配录音命名规则”。关闭统一命名时保留原文件名上传。
2. 不默认用文件最后修改时间替代录音时间。仅在设置中明确启用“文件修改时间兜底”时允许，并将来源标记为“推测”。
3. 同一手机号、同一秒生成同名文件：不覆盖、不改名，标记为“命名冲突，需人工处理”。
4. 原始文件名中的联系人名、客户号码等信息不上传到目标文件名。

## 4. 核心数据流

```text
用户保存 SMB 与命名配置
  → 测试目标 SMB 目录的读写能力
  → WorkManager 扫描已授权录音目录
  → 按机型规则解析原始文件名中的录音开始时间
  → 按开关生成 手机号_yyyyMMddHHmmss.原扩展名 或保留原文件名
  → 写入本地上传队列（待上传）
  → 建立 Guest 或账号密码 SMB 会话
  → 可选创建 设备名称 子目录
  → 写入 .uploading 临时文件
  → 校验远端大小并改名为正式 MP3
  → 标记已上传
  → 后端质检脚本只读取正式 MP3
```

## 5. 数据库调整

在现有 `app_config` 增加：

| 字段 | 类型/示例 | 用途 |
|---|---|---|
| `salesPhoneNumber` | `13800138000` | 文件名前缀。 |
| `deviceName` | `张三` | SMB 子目录名称。 |
| `authMode` | `GUEST` / `PASSWORD` | SMB 登录方式。 |
| `createDeviceSubfolder` | `true/false` | 是否创建并使用设备子目录。 |
| `recordingParseProfile` | `HUAWEI_14_DIGITS` | 当前机型时间解析规则。 |
| `customFilenameRegex` | 可空 | 自定义规则的正则。 |
| `customDateFormat` | 可空 | 自定义规则的日期格式。 |
| `allowModifiedTimeFallback` | `true/false` | 是否允许推测时间兜底，默认 `false`。 |
| `verificationMode` | `SIZE_ONLY` / `SHA256` | 上传后的复核级别。 |
| `autoSyncEnabled` | `true/false` | 是否自动同步。 |
| `syncScheduleMode` | `DAILY` / `INTERVAL` | 每日定时或间隔同步。 |
| `dailySyncHour`、`dailySyncMinute` | `2`、`0` | 每日同步时间。 |
| `intervalMinutes` | `1440` | 间隔同步分钟数，最小 15 分钟。 |

在 `recordings` 增加：

| 字段 | 用途 |
|---|---|
| `recordedAtSource` | `FILENAME` / `MODIFIED_TIME`，标明时间可信来源。 |
| `targetDirectory` | 实际上传到的 SMB 子目录，便于排查。 |

数据库版本升级时提供 Room Migration，保留已有 SMB、目录和上传记录；既有 `deviceCode` 迁移后不再用于文件命名。

## 6. UI 要求

### 设置页

- 使用“访客模式”开关或登录方式单选；访客模式下隐藏用户名、密码。
- 对中文共享名和设备名称允许输入，但在连接前做合法性提示（不允许 `/`、`\\`、控制字符）。
- 保存后可点击“测试连接”。测试过程展示“连接中”，完成后显示具体结果，例如“已成功在 /岗位/张三 创建测试文件”。
- 自定义时间正则要求第 1 个捕获组为 14 位时间；无法识别时明确提示，不猜测录音时间。

### 首页

- 待上传数量、最近成功时间、最近错误、立即同步与延后同步。
- 失败列表展示原文件名、失败原因、可重试操作。

## 7. 验收标准

1. 无用户名、无密码的 SMB Guest 共享可测试连接并完成上传。
2. 用户名密码 SMB 共享仍可正常上传，密码不以明文写入数据库或日志。
3. `192.168.110.28` 的中文共享名“岗位”可作为测试样例成功访问。
4. 勾选设备子目录后，可将文件上传到“共享目录/张三/”；不勾选则直接上传到共享根目录。
5. 统一命名开启时，上传名均为 `11位纯数字手机号_14位纯数字时间.原始扩展名`；关闭时保留原文件名。
6. 无法准确识别录音发生时间时，文件不会被错误命名并上传。
7. 测试连接和上传网络操作均在后台线程执行；界面必须显示可定位的失败原因，而不是统一的模糊报错。
8. 上传中断后，服务器不出现可被后端读取的半成品正式音频文件；大小校验或 SHA-256 校验失败时不标记成功。

## 8. 实施顺序

1. 修复测试连接的后台执行与真实错误展示。
2. 增加 Guest 登录、中文路径编码与设备子目录。
3. 增加手机号、设备名称、统一命名开关及原始扩展名保留。
4. 增加自定义时间正则、自动同步调度和上传复核。
5. 完成 Room Migration、回归测试，并重新生成 APK。
