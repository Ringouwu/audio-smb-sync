# 录音 SMB 同步 Android MVP

把销售手机中已存在、并由用户授权读取的 MP3 录音上传到同一局域网的 MacBook SMB 共享目录。App 不录制电话、不删除源录音，也不包含质检逻辑。

## 使用流程

1. 在 MacBook 开启 SMB 文件共享，并创建专用共享目录和可写账号。
2. 安装 App，填写设备编码、MacBook IP、共享名、账号密码。
3. 用系统目录选择器选择手机厂商通话录音目录。
4. 测试连接；成功后点击“立即同步”验证。
5. App 每日约凌晨 02:00 自动扫描并上传。Android 会因省电策略稍后执行。

上传采用临时后缀 `.uploading`，校验完文件大小才改为 MP3 正式文件。后端质检脚本只应读取 `.mp3` 文件。

详见 [MacBook SMB 配置](docs/MacBook_SMB配置.md) 和 [试点部署说明](docs/试点部署说明.md)。
