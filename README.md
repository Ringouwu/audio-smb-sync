# 录音 SMB 同步 Android MVP

把销售手机中已存在、并由用户授权读取的录音上传到同一局域网 SMB 共享目录。支持访客 SMB 与账号密码 SMB；App 不录制电话、不删除源录音，也不包含质检逻辑。

## 使用流程

1. 在 SMB 服务器开启文件共享，并创建可写共享目录（可使用访客模式或账号密码）。
2. 安装 App，填写销售手机号、设备名称、服务器 IP、共享名和登录方式。
3. 用系统目录选择器选择手机厂商通话录音目录。
4. 测试连接；成功后点击“立即同步”验证。
5. 按需开启每日定时或间隔自动同步，也可立即或延后同步。Android 会因省电策略稍后执行。

上传采用临时后缀 `.uploading`，校验完大小（可选 SHA-256）才改为正式音频文件。后端质检脚本只应读取非 `.uploading` 文件。
